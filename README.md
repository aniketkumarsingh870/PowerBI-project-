Online course analytics dashboard 
📊 Online Course Analytics Dashboard | Power BI Project
Excited to share my latest Power BI Dashboard, built to analyze the performance of an online learning platform and turn raw data into meaningful, actionable insights. 🚀
For this project, I worked on the complete analytics workflow — from data cleaning and transformation in Power Query to data modeling, DAX measures, KPI development, and interactive visualization in Power BI.
📌 Key insights covered in the dashboard: • 10,000 total enrollments
• ₹24.5L total revenue
• 4.35 average course rating
• 82.35% course completion rate
• Students across 25 countries
• Monthly enrollment trends
• Revenue performance by course category
• Top courses based on revenue
• Global student distribution
• Category-wise ratings and completion analysis
🎯 I also implemented interactive slicers and filters for Date, Country, Category, Course Name, and Completion Status, allowing users to explore the data dynamically.
🛠️ Tools & Skills Used:
Power BI | Power Query | DAX | Data Modeling | Data Cleaning | KPI Development | Data Visualization | Data Storytelling
This project helped me understand that creating a dashboard isn't just about making attractive charts — it's about transforming data into a story that supports better decisions.
